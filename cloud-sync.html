Cloud Setup

Supabase · Private account · Manual device transfer

Demo / pilot only — do not enter real client information.

This prototype still keeps plaintext data in device storage. Supabase is not connected until you configure your project and log in. Cloud upload and download are manual, not automatic sync.

1. Supabase connection

This demo is preconfigured for your Supabase project on every new device.

First run the SQL in supabase/schema.sql and follow setup instructions. Use a publishable/anon key. Never paste a service_role or secret key here.

2. Sign in

Each device needs its own login session. Magic links are rate-limited. If your Supabase user already has a password, you can sign in without email.

Not connected

3. Move demo data between devices

Optional Auto Sync (pilot)

Requires one SQL migration and a cloud snapshot. Enabling will download the current cloud snapshot and replace this device's local demo records. Future changes sync automatically when online. Conflicts pause synchronization instead of overwriting.

Auto sync: Off

Cloud Backup & Recovery (pilot)

History is created before each cloud update only AFTER you run backup-history.sql. Existing versions from before migration are not retroactively recoverable. Recovery replaces the entire cloud snapshot and requires confirmation.
